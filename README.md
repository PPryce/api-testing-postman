# api-testing-postman

Automated REST API testing using Postman covering positive, negative, boundary and error-handling scenarios. Tests validate HTTP status codes, response schemas, headers, authentication and response data.

- GET /users
- POST /users
- PUT /users
- DELETE /users
- Invalid authentication
- Missing mandatory fields
- Invalid data types
- Boundary values
- 400/401/403/404/500 responses
- JSON schema validation
